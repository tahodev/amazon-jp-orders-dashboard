# Chrome Web Store submission checklist

## Prepared by the repository

- [x] Manifest V3
- [x] Store name and description within manifest limits
- [x] `scripting` is the only named permission
- [x] Host access limited to Amazon.co.jp and `127.0.0.1:8776`
- [x] 16, 32, 48, and 128px PNG icons
- [x] Extension ZIP with `manifest.json` at archive root
- [x] 1280x800 screenshots and 440x280 promo tile
- [x] Japanese and English listing copy
- [x] Bilingual privacy policy and Limited Use disclosure
- [x] Reviewer setup and test instructions
- [x] No remote code, telemetry, advertising, or cloud order-data transfer

## Publisher actions required

- [ ] Choose the long-term Google publisher account
- [ ] Enable Google 2-Step Verification
- [ ] Accept the Chrome Web Store developer agreement
- [ ] Pay the one-time developer registration fee
- [ ] Verify the developer contact email
- [ ] Decide trader/non-trader status based on the publisher's own circumstances
- [ ] Upload the extension ZIP
- [ ] Paste and verify Store Listing and Privacy practices fields
- [ ] Upload screenshots, icon, and small promo tile
- [ ] Select public distribution countries
- [ ] Review all data-use certifications personally
- [ ] Submit for review, preferably with deferred publishing for the first release

Do not upload GitHub credentials, Amazon credentials, the local `data/` directory, screenshots of real orders, or any private fixture.
