# Chrome Web Store listing (English)

## Name

Amazon JP Orders - Local Spending Dashboard

## Short description

Save Amazon.co.jp order history locally and create monthly, category, and CSV spending summaries.

## Detailed description

Turn your signed-in Amazon.co.jp order history into a private spending dashboard on your own computer.

When you start a sync, the extension reads the relevant order-history and order-detail pages and saves the results through a companion receiver running on the same computer. Order data is never sent to the maintainers or a cloud analytics service.

Features:

- one-click incremental sync for recent orders;
- explicit year and date-range capture for backfilling history;
- item-level details for multi-item orders;
- monthly and category spending charts;
- editable category corrections;
- SQLite, CSV, JSON, and local HTML outputs.

First-time setup requires the free local receiver from the GitHub Release and Python 3.10 or later.

The extension never buys, cancels, returns, changes payment methods, or modifies account settings. It does not store Amazon passwords, cookies, or payment-card numbers.

This independent project is not affiliated with or endorsed by Amazon.
