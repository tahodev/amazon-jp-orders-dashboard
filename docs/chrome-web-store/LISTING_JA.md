# Chrome Web Store掲載文（日本語）

## 商品名

Amazon JP Orders - ローカル支出ダッシュボード

## 概要

Amazon.co.jpの注文履歴をPC内だけに保存し、月別・カテゴリ別の支出ダッシュボードとCSVを作成します。

## 詳細説明

Amazon.co.jpの注文履歴を、毎月の支出確認に使いやすいローカルダッシュボードへ変換します。

拡張機能から同期を開始すると、ログイン済みの注文履歴ページと注文内容ページを読み取り、同じPC上で動くローカル受信サービスへ保存します。注文データを開発者や外部のクラウドサービスへ送信することはありません。

主な機能：

- 最新注文をワンクリックで差分同期
- 年と開始日・終了日を指定した過去注文の取込
- 複数商品を含む注文の商品別明細
- 月別・カテゴリ別の支出グラフ
- 商品カテゴリの手動修正と学習
- SQLite、CSV、JSON、ローカルHTMLへの出力

初回利用時は、GitHub Releaseから無料のローカル受信サービスをダウンロードし、`start_dashboard.bat`を起動してください。Python 3.10以降が必要です。

本拡張機能は購入、キャンセル、返品、支払方法、アカウント設定を操作しません。Amazonのパスワード、Cookie、カード番号は保存しません。

本プロジェクトはAmazonとは関係なく、Amazonによる承認・支援を受けていません。
